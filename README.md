## Mika

Local-first desktop software for Linux and Windows, written in Rust, Python with Qt Quick, and C++.

I build tools I use myself, and I keep them small.

### Desktop apps
- [**Rewa**](https://github.com/mikaeww/Rewa): instant replay recorder for Windows and Arch Linux, GPU-encoded and held in memory (*Rust*)
- [**Calendary**](https://github.com/mikaeww/calendary): desktop calendar for Google and iCloud calendars, with a Windows installer (*Python, Qt Quick*)
- [**Filyy**](https://github.com/mikaeww/filyy): keyboard-friendly file manager for Hyprland (*Python, Qt Quick*)

### Tools
- [**PIDRA**](https://github.com/mikaeww/PIDRA): keyboard-first process manager for the terminal (*Rust, Ratatui*)
- [**Crosshype**](https://github.com/mikaeww/Crosshype): crosshair overlay for Wayland, with a TUI builder that previews the real overlay (*Python*)
- [**Blinky**](https://github.com/mikaeww/blinky): a small character for every Claude Code and Codex session, sitting on its terminal (*Python, QML*)

### Open source
- Ported [**boltsnap**](https://github.com/drvcvt/boltsnap) and [**eddy**](https://github.com/drvcvt/eddy) to Windows: native capture, MSI and NSIS installers, release CI
